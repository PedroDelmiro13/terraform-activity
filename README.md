# Projeto Terraform com AWS

Este projeto pratica a criacao de infraestrutura na AWS usando Terraform e arquivos HCL.

A documentacao completa do processo de conexao com a Cloud AWS, dos comandos de execucao e dos aprendizados da aula esta em [readme.me](readme.me).

Resumo do fluxo:

```text
terraform init
terraform fmt
terraform plan
terraform apply
```

As credenciais devem ser configuradas pela AWS CLI ou por um perfil IAM local. Nunca coloque chaves de acesso nos arquivos Terraform ou no repositorio.
